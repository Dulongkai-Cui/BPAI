## 1. 使用方法

当你看到 `AI_Dev_Memo/Project_skeleton/**` 中的能力设想，想知道它现在在代码里落到了哪里，就先查这张表：

- `已实现`：当前代码中已能定位到对应页面/API/schema/service
- `部分实现`：已有骨架或局部链路，但未形成完整闭环
- `待实现`：PRD 里有，但当前正式代码中未看到真实承接

- 当前代码已开始 Postgres 化
- 但仍保留 `mock-data`、`app-store`、`raw-shadow` 过渡层

### 6.3 多人实时协作细节
- 文档协作入口与浏览器状态已存在
- 但像多人实时评论、权限锁、复杂冲突处理，不应仅凭 PRD 判断为已完整实现

## 7. 后续开发时如何用本页

### 如果你要做“对齐 PRD 的新功能”
1. 先看本页是否标记为 `已实现 / 部分实现 / 待实现`
2. 再跳到 `00-05` 的事实文档确认代码入口
3. 若只有 PRD 没有代码锚点，就把它当新功能而不是小修改

### 如果你要判断某能力是否能直接复用
- 看它是否已有：
  - 页面入口
  - API route
  - server service
  - schema 表/字段
- 四者至少满足 2-3 个，才适合说“已有半成品可接着做”

### 如果你要给 AI 下文档导航提示
推荐让 AI 先读：
- `00_总索引与导航.md`
- 对应事实层文档（01-05）
- 最后才读本页

避免 AI 先读规划，再把规划误当成现状。
