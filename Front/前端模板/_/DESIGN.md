# Design System Documentation

## Theme Overview

This document outlines the core design principles and theme specifications for our digital products.

### Color Palette

Our color palette is built around a "rainbow" variant, providing a diverse and vibrant range of hues derived from a seed color.

- **Primary Color**: `#4777c2` - Used for primary actions, key interactive elements, and branding.
- **Secondary Color**: `#6e778a` - Supports primary elements, suitable for less prominent UI components and secondary actions.
- **Tertiary Color**: `#896e8e` - An accent color for highlights, badges, and decorative elements.
- **Neutral Color**: `#777777` - Forms the foundation for backgrounds, surfaces, and non-chromatic UI elements.
- **Color Mode**: Our system operates in a `light` mode.

### Typography

Our typography system uses a consistent font family across various text elements to ensure readability and a unified aesthetic.

- **Headline Font**: `inter` - Applied to all headlines and prominent display text.
- **Body Font**: `inter` - Used for paragraph text, descriptions, and general content.
- **Label Font**: `inter` - Designated for form labels, buttons, and interactive element labels.

### Shape and Form

The visual characteristics of our UI components are defined by their roundedness.

- **Roundedness**: `2` - Components feature a moderate level of roundedness, striking a balance between modern softness and clarity.

### Spacing

Our spacing system governs the internal and external distances between UI elements, contributing to layout coherence and visual hierarchy.

- **Spacing**: `2` - A normal level of spacing is applied, providing a balanced and comfortable user interface.
